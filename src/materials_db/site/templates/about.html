About {{ brand }}

{{ brand }} is an open database of optical constants (refractive index n, extinction coefficient k and permittivity ε) in which every dataset is tied to its source publication. It is the materials service of {{ library }}, the open photonics suite.

Where the data come from

The content is the complete refractiveindex.info database by M. N. Polyanskiy, released into the public domain (CC0 1.0) and imported unchanged at a pinned commit of its repository{% if snapshot %} ({{ snapshot.commit[:10] }}{% if snapshot.imported_at %}, imported {{ snapshot.imported_at.strftime("%Y-%m-%d") }}{% endif %}){% endif %}. Shelves, books, pages and their order are kept, so each page here corresponds to one page there. {{ brand }} is not affiliated with refractiveindex.info. Community contributions are reviewed by moderators before they appear.

How to cite

Conventions

  • Wavelengths are vacuum wavelengths. Pages show µm, as the source does; the API uses nm.
  • Time dependence exp(−iωt), so absorbing media have k > 0 and Im ε > 0, the same as the {{ library }} library.
  • Tables are interpolated linearly and never extrapolated; formulas are evaluated exactly.
  • Data are shown as published. Problems found in the source data (k < 0, for example) are flagged on the page.

Numbers in your code

Every dataset page has copy-paste Python for the {{ library }} library. The REST API serves the same data as JSON, CSV, tab-separated text and YAML: see the interactive API reference.
